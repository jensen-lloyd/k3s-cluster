Make new cert:
sudo certbot certonly --config certbot-wildcard.ini


Update k3s secret with cert: (updates in default, Reflector copies it to specified namespaces)

sudo kubectl create secret tls wildcard-colins-io-tls \
  --cert=/etc/letsencrypt/live/colins.io/fullchain.pem \
  --key=/etc/letsencrypt/live/colins.io/privkey.pem \
  -n default \
  --dry-run=client -o yaml | sudo kubectl apply -f -



Check:

kubectl get secret wildcard-colins-io-tls -n default




To renew:
re-run the first command
then re-create the kubernetes secret



To add Reflector to new namespaces:
sudo kubectl annotate secret wildcard-colins-io-tls -n default \
  reflector.v1.k8s.emberstack.com/reflection-auto-namespaces="focus-board,job-seekr,joplin" \
  --overwrite
